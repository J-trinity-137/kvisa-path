# kvisa-path — K-Visa 학생 진로·입시 스킬트리

## 해결하는 문제
- 외국인가정·중도입국 중·고등학생(대학 진학 희망 71.6%, 고교 자퇴율 2.20%)이 부모 체류자격(비자)별 고입·대입·취업 경로를 몰라 진학을 포기하는 정보 격차 해결
- 미등록 이주아동 보호를 위해 **체류자격은 서버에 일절 저장하지 않는 무상태(Stateless) 조회** 원칙 적용

## 연동 공공 Open API
- 커리어넷 Open API: 진로심리검사, 직업백과, 주니어직업정보, 학과정보
- 서울열린데이터광장: 서울외국인포털 진로·진학 컨설팅 정보(`OA-21713`)

## 수집·분석 데이터 (PII 제로)
- 비자 미저장 원칙 준수, 익명 학년·관심 학과/직업·정보 단절 질문 토픽만 수집
- 핵심 지표: 진로정보 탐색 격차 지수(CIGI), 7일 상담 연결확인율

## 실행
```bash
npm install
npm run dev   # http://localhost:5203
```
